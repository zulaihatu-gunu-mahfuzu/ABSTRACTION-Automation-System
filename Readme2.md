# Building Automation System

# Overview

This project demonstrates Abstraction, Inheritance, and Polymorphism in Python using the abc module.

# Features

. Abstract class: BuildingSystem
. Abstract methods: start(), stop(), and status()
. Child classes: 
  -AirConditioningSystem
  -LightingSystem
  -SecuritySystem
  -FireAlarmSystem

. Polymorphic processing using a list of system objects

# Key Concepts Demonstrated

. Abstraction with ABC and @abstractmethod
. Inheritance between parent and child classes
. Polymorphism through a common interface
. Extensibility without changing existing processing logic
